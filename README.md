Zifbin
------

Yet another pastebin project. Powers [Zifbin](https://zifb.in) and [Vomit Bin](https://vomitb.in).

This project now uses Docker and requires Python 3 (it's been tested with 3.14).

The CLI will remain py2 compat, but will not be tested after January 1st, 2020.
